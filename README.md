# FitTrack — Fitness Progress Tracker

A modern, responsive fitness tracking web application built with React and Vite.

FitTrack allows users to create and manage workouts, browse exercises, set fitness goals, track completed workouts, and review their workout history. The project was built as a portfolio application to demonstrate practical React development skills, component-based architecture, state management, routing, form handling, and browser data persistence.

---

## Description

FitTrack is a single-page fitness management application designed to provide users with a simple and intuitive way to organize their fitness routine.

The application includes separate sections for workouts, exercises, fitness goals, and workout history. Users can create, edit, and delete workouts and goals, customize exercises with sets and repetitions, complete workouts, and maintain a persistent workout history.

The project focuses on building a realistic React application rather than a collection of isolated coding exercises.
